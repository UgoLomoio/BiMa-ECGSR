# BiMa-ECGSR preprocessing (PTB-XL, Georgia, China)

> Generated by `bima_ecgsr/data/build_dataset.py` together with the dataset in `$BIMA_DATA_DIR` (copied here verbatim apart from this title). The pipeline sha256 quoted below is that of `pipeline.py` at build time; the copy in this repository differs only in its docstring/comments (signal and label code unchanged, see REPO_ASSEMBLY_REPORT.md).

Methods text:

All ECGs were processed with a single pipeline (`pipeline.py`, sha256 bc52148cafe6) applied identically to PTB-XL v1.0.3 (records500), the Georgia 12-lead database (10,344 records) and the Chapman-Shaoxing/Ningbo ecg-arrhythmia v1.0.0 database (China, 45,152 records); no records were subsampled.
Records were read with wfdb in physical units (mV) and the twelve leads were reordered by header lead name to I, II, III, aVR, aVL, aVF, V1-V6; all readable records were natively sampled at 500 Hz (header fs values: 500.0), so no resampling was needed, and the first 10.0 s (5,000 samples) were kept; records shorter than 10 s were excluded.
Each 10-s record was band-pass filtered with a zero-phase third-order Butterworth filter (0.5-40 Hz, second-order sections, scipy.signal.sosfiltfilt, effective magnitude |H(f)|^2 with -6 dB at both cut-offs, i.e. -0.0 dB at 10 Hz, -14.4 dB at 50 Hz and -23.5 dB at 60 Hz, so mains interference is attenuated rather than notched).
Filtered records were split into two non-overlapping 5-s windows (0-5 s and 5-10 s; 2,500 samples), and each lead of each window was z-scored with its own mean and standard deviation.
A window was excluded if it contained any non-finite value or any lead with a pre-normalisation standard deviation below 0.005 mV (flat lead); all exclusions were logged with their reason, and windows were stored as float16 arrays of shape [N, 12, 2500].
PTB-XL was split by the recommended strat_fold (folds 1-8 training, 9 validation, 10 test; patient-disjoint), giving 34,833 / 4,366 / 4,396 windows from 17,417 / 2,183 / 2,198 records; Georgia (20,547 windows, 10,275 records) and China (87,105 windows, 43,559 records) were used only as external test sets.
PTB-XL diagnostic superclasses (NORM, MI, STTC, CD, HYP) were derived as multi-hot labels from all scp_codes with diagnostic = 1 in scp_statements.csv, regardless of likelihood.
A shared 12-label rhythm/morphology panel (AFIB, AFLT, 1AVB, PAC, PVC, SBRAD, STACH, WPW, LVH, RVH, CRBBB, CLBBB) was defined by SCP-code presence in PTB-XL and by a fixed SNOMED-CT mapping in the external cohorts (PVC = 17338001 or 427172004; CRBBB = 713427006 or 59118001; CLBBB = 733534002 or 164909002, following the PhysioNet/CinC 2021 scoring equivalences; incomplete RBBB, 713426002, is not CRBBB).
External labels are annotation-reference labels: a label is unknown when the record has no Dx code or carries a code that is ambiguous for that target (195080001 or 164890007 for AFIB, 195080001 for AFLT, 63593006 for PAC), and negative otherwise.
Label caveats (China): all 7,959 AFLT-positive records carry SNOMED 164890007, the code that the canonical mapping treats as ambiguous for AFIB because these records are as RR-irregular as AFIB; the China dictionary assigns 164909002 to LBBB and to left front/back bundle-branch block; and 34 China records are positive for both CRBBB and CLBBB.
For every window, the band-passed per-lead mean and standard deviation (mV) used for the z-score were stored as float32 arrays `STATS_<suffix>.npy` of shape [N, 12, 2] (mean_mV, std_mV; same row order as the X and meta files), so absolute band-passed amplitudes, and therefore inter-lead amplitude ratios, can be restored as x_mV = z * std + mean. The STATS files were added later (2026-11-10T19:14:07+00:00) with the same pipeline code in `--stats-only` mode, which re-ran the whole chain and verified that the existing X, meta, exclusion and val_select files were byte-identical (SHA-256 unchanged) before writing only the STATS files.
For model selection, a fixed subset of 1,024 PTB-XL validation windows was drawn with numpy default_rng(0) (`val_select_1024.npy`).

Parameters: fs = 500 Hz; duration = 10.0 s (5000 samples); band = (0.5, 40.0) Hz; Butterworth N = 3 (bandpass, sos, sosfiltfilt default odd padding); windows = 2 x 2500 samples; flat-lead threshold = 0.005 mV (std of band-passed window); z-score per window per lead (population std); storage float16.
